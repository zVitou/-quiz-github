# Quiz: Qual personagem de Dragon Ball você seria?

Um quiz interativo feito em HTML, CSS e JavaScript, para descobrir com qual personagem de **Dragon Ball** o participante mais se identifica, de acordo com suas respostas.

## Sobre o projeto

O quiz apresenta 8 perguntas. Cada resposta soma pontos para um personagem, e no final é exibido aquele que teve a maior pontuação.

## Personagens possíveis

- Goku
- Vegeta
- Gohan
- Piccolo
- Bulma
- Kuririn

## Funcionalidades

- Tela inicial para começar o quiz.
- 8 perguntas com alternativas.
- Barra de progresso para acompanhar o andamento.
- Sistema de pontuação para definir o resultado.
- Tela final com o personagem correspondente.
- Botão para reiniciar e fazer o quiz novamente.

## Tecnologias utilizadas

- **HTML5:** estrutura da página.
- **CSS3:** aparência e estilização.
- **JavaScript:** perguntas, pontuação, progresso e resultado.

## Como executar

1. Acesse o repositório e baixe os arquivos, ou clone o projeto:
   `git clone https://github.com/zVitou/-quiz-github.git`
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.

## Estrutura do projeto

```text
- index.html
```

O CSS e o JavaScript estão incorporados no próprio arquivo HTML.
